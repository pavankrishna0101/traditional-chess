# Traditional Chess

A terminal-based chess game written in C++.

## Features

- Legal move validation
- Check detection
- Checkmate detection
- Stalemate detection
- Castling
- En passant
- Pawn promotion
- Insufficient material detection

## Technologies

- C++
- STL

## Future Improvements

- Graphical user interface
- Chess engine (Minimax + Alpha-Beta)
- Move history
- FEN support
